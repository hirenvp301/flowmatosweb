Four-agent architecture
How AccountLens works
AGENT 01
Account Resolution
IP enrichment → Salesforce domain match → returns ICP tier, deal stage, open opportunity value, AE owner. Three-layer cache: in-memory → Redis → DynamoDB. p95 latency target: <50ms.
Redis · DynamoDB · Salesforce API
AGENT 02
Audience & Intent
Enriches account context with Adobe AEP behavioral signals, segment membership, prior content consumption, and persona classification. Builds the full decision context object.
Adobe AEP · Segment API · Behavioral signals
AGENT 03
Content Decision (LLM)
Queries AEM content index, scores variants against context using weighted formula (industry 35%, funnel stage 30%, ICP tier 20%, persona 15%). Below threshold: Claude on Amazon Bedrock generates compliant copy.
Claude · Amazon Bedrock · AEM Content Index
AGENT 04
Delivery & Test
Injects content payload at AEM Sling Model render hook. Maintains 20% holdout group. Coordinates with Adobe Target for existing A/B activities. Triggers async AE pre-call brief pipeline.
AEM Sling Models · Adobe Target · Slack
