How SignalMint works
AGT 1

Query Runner Agent

Probes Claude, ChatGPT, and Gemini with buying-stage queries built from your brand profile — category, ICP, and competitor list — across four stages: awareness, consideration, evaluation, and competitive. Records full response, brand mention flag, competitor mentions, and sentiment. Runs all three engines in parallel with bounded concurrency.

Anthropic API · OpenAI API · Google Gemini API
AGT 2

Gap Detector Agent

Analyses query results and scores each citation gap 0–100 using a weighted urgency formula: priority weight (high=40, medium=25, low=10), stage weight (late_stage=20, competitive=18, evaluation=15), competitive gap bonus (+30 when competitor cited without brand), multi-engine penalty (+5 per additional engine miss).

Weighted scoring · Competitor exposure report · JSON output
AGT 3

Brief Generator Agent

Uses Claude to generate a structured content brief for each top-ranked gap: a BLUF answer (2–3 sentences AI can cite directly), FAQ block (5–8 questions with 80-word answers), FAQPage JSON-LD schema, and Article JSON-LD schema. Briefs are saved to your dashboard ready to copy into any CMS.

Claude (Anthropic API) · Supabase · Inngest
